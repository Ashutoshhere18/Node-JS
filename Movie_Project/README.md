
# 🎬 Movie Manager — Full Stack Project

A modern **Movie Management Application** built with **React, Node.js, Express, and MongoDB**, featuring a premium glassmorphism UI and complete backend integration with file uploads.

This project demonstrates **real-world full-stack development skills**, including API design, database operations, and polished frontend UX.

---

## ✨ Features

✅ Add movies with poster upload  
✅ View all movies in a clean, responsive UI  
✅ Update movie details in real time  
✅ Delete movies from database & UI instantly  
✅ RESTful API tested with Postman  
✅ Glassmorphism-inspired modern UI  

---

## 🛠️ Tech Stack

### Frontend
- ⚛️ React (Hooks)
- 🎨 Custom CSS (Glassmorphism UI)
- 🔗 Axios

### Backend
- 🟢 Node.js
- 🚀 Express.js
- 🍃 MongoDB (Mongoose)
- 📂 Multer (Image Uploads)

### Tools
- 🧪 Postman (API Testing)
- 🗄 MongoDB Compass

## 🔄 API Overview

| Method | Endpoint | Description |
|------|--------|------------|
| POST | `/` | Add a new movie |
| GET | `/` | Fetch all movies |
| PUT | `/:id` | Update movie details |
| DELETE | `/:id` | Delete movie |

✔ All APIs tested and verified using **Postman**
