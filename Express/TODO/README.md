
# 📝 Todos API Development

Welcome to the **Todos API** project! 🚀  
This is a lightweight backend API for managing todos, built with **Node.js and Express**. The API supports full CRUD operations along with basic filtering features for simple task management.  

---

## 🎯 Project Overview

The goal of this project is to develop a **simple, easy-to-use API** that allows clients to:

- Create new todos ✅
- Read all or filtered todos 📋
- Update existing todos ✏️
- Delete todos 🗑️
- Filter todos by completion status 🔍  

This project is perfect for beginners learning **API development with Node.js and Express**.  

---

## 🛠️ Technologies Used

- **Node.js** – JavaScript runtime for server-side programming 🌐  
- **Express.js** – Web framework for creating API endpoints ⚡  
- **In-memory storage / JSON** – Simple data storage for todos 🗂️  
- **Postman** – API testing tool 🧪  

---

## 🗂️ API Endpoints

| Method | Endpoint                     | Description                                    |
| ------ | ---------------------------- | ---------------------------------------------- |
| POST   | `/api/todos`                 | Create a new todo                              |
| GET    | `/api/todos`                 | Get all todos                                  |
| GET    | `/api/todos?status=`         | Get todos filtered by completion status        |
| GET    | `/api/todos?title=`          | Get todos filtered by title                    |
| PUT    | `/api/todos`                 | Update a todo (e.g., mark as completed)        |


## 💡 Features

* ✅ Full CRUD functionality
* 🔍 Filtering by status (`isCompleted`)
* 🧩 Easy to extend or integrate with frontend apps
* 📚 Clear and structured codebase for learning purposes
